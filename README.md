# msa_files
Bachelor Project

With this Shiny application it is possible to explore conserved phosphosites within some protein alignments of orthologs of Yeast, Arabidopsis and Human.

A new version of the App was uploaded, which uses a new scoring system. The variable t(x) of the scoring formula was updated to a normalized version of the Relative von Neumann Entropy (08.05.2025).

Just download the Shiny_App_Phosphosites Markdown file and launch it, e.g. in RStudio.
